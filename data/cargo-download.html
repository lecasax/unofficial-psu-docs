Cargo downloads

The wiki returns at most 512 rows per export, so each table comes in pages. Open every link (they open in a new tab), save each one with Ctrl+S (or "Save" in Firefox's JSON viewer), and put all the files in data/raw/cargo/. File names do not matter: the build script finds the table by its fields.

If the last page of a table has exactly 512 rows, the table grew: add a page here.
